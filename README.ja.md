# 漢字テストメーカー · Kanji Test Maker

[English](README.md) | **日本語**

先生のための無料ツールです。今週の漢字を選ぶか、自分で文を貼り付けると、縦書きの
漢字テストが **PDF** と編集できる **Word (.docx)** でできあがります。解答シートも
必要なら作れます。

処理はすべてブラウザ内で行われます。アカウントは不要で、どこにもアップロードされず、
入力した文がパソコンの外に出ることはありません。

## 今すぐ使う

**https://hikashop-nicolas.github.io/kanji-test-maker/**

インストールは不要です。アプリとしてパソコンに追加することもできます。上のリンクを
開き、ブラウザのインストールボタン（Chrome ならアドレスバー右のアイコン、Safari なら
ファイル ▸ Dock に追加）を使ってください。ふつうのアプリと同じように独立した
ウィンドウで開き、インターネットがなくても使えます。

辞書・フォント・文字認識のデータは大きいため、最初にまとめてダウンロードすることは
しません。使ったときに保存され、それ以降はオフラインでも使えます。

## テストを作る

学年からそのまま作ることも、自分の文を貼り付けることもできます（後者は
[自分の文を使う](#自分の文を使う)を参照）。

**1. レベルを選び、漢字を選ぶ。** 学年（小1〜小6、または中学以降の常用漢字）か JLPT
レベル（N5〜N1）を選びます。表は画数順、つぎに部首順という、先生が探しやすい順に
並びます。クリックで選ぶか、ほかのレベルの漢字も含めて直接入力できます。

![学年と漢字を選ぶ](docs/screenshots/01-pick-kanji.png)

**2. 例文を選ぶ。** 漢字ごとに、やさしく定着しやすい文が上に来るように並び、対象の
漢字が強調表示されます。「やさしい文だけ」にチェックすると、そのレベル以下の漢字だけの
文に絞れます。

![例文を選ぶ](docs/screenshots/02-pick-sentences.png)

**3. 表で調整する。** チェックした文は編集表に入り、レッスンの漢字にはすでにマークが
付いています。語をクリックすると、その語の扱いが切り替わります。

- そのまま（グレー）：書かれたまま表示します。
- テスト（青）：解答欄（マス）になります。
- ふりがな（オレンジ）：漢字はそのままで、ふりがなを付けます。
- ひらがな（赤）：漢字を読みに置き換えます。例文から追加した文は、選んだレベルより
  上の語が最初からこの状態になっています。

文ごとに 書き（読みを見せて漢字を書かせる）か 読み（漢字を見せて読みを書かせる）かを
選べます。表の上のボタンは**すべての文**をまとめて切り替えるので、同じ文のセットから
書きのテストと読みのテストを、1文ずつ切り替えずに作れます。

解析が読みを取り違えたときは、その場で直せます。

![表で調整する](docs/screenshots/03-edit-table.png)

**4. テストを保存する。** 「**PDF を保存**」で印刷用の PDF、「**Word (.docx) を保存**」で
編集できる文書ができます。.docx にはフォントが埋め込まれるので、そのフォントが入って
いないパソコンでも正しく表示されます。「**解答シートも作成する**」にチェックすると、
すべてのマスを埋めた解答シートも作れます。

![作成されたテスト](docs/screenshots/04-worksheet.png)

## 自分の文を使う

**貼り付ける。** 「文を貼り付け」タブに1行1文で、ふつうに漢字を使って入力し、「解析する」を
クリックします。漢字の語は自動で検出・マークされ、あとは上と同じ表で調整できます。
すぐ試せる例文集は `test_sentences.md` にあります。

**ファイルから読み取る。** 「ファイルから」タブでは、PDF や、教科書のページ・古い
プリントの写真やスキャンから日本語を読み取れます。ファイルがどこかに送られることは
なく、お使いのパソコンの中だけで処理されます。

Word や Excel などで作られた PDF は文字データを持っているので、縦書きも含めて、
入力されたとおりの文がそのまま取り出せます。スキャンしただけの PDF には文字データが
ないため、そのページは画像と同じように文字認識にかけます。

文字認識にかける場合は、縦書きなら先に「縦書き」にチェックを入れてください。読み取り方が
変わり、文になるか意味不明な文字列になるかの分かれ目になります。家庭用スキャナーでは
認識は完璧ではありません。読み取った行は編集できる欄に入るので、目を通して、おかしい
ところを直すか消してから追加してください。

## レイアウト

「見た目・レイアウト」で設定できます。

- **1ページの文数。** 「自動」のままなら、ページに入るだけ配置します。チェックを
  外すと、文数を指定できます。
- **1ページの段数。** 1段（列が全高）か、2段（短い文向け）を選べます。短い文は
  1段だとページの下半分が空いてしまいます。
- **マスの位置。** 文中（日本で一般的な配置で、既定）に置き、漢字の位置にマス、その
  横に読みを入れるか、横の欄に置くかを選べます。
- **フォントとサイズ。** 日本語フォント6種（既定は Klee One。手書きに近い字形で低学年
  向き）、パソコンに入っているフォント、またはアップロードしたフォントファイルが
  使えます。文字の大きさとマスの大きさは別々に指定できます。
- **追加要素。** 名前の下の点数欄・保護者印の欄と、左下のロゴ。複数ページのときの
  ページ番号は自動で付きます。

文がページに収まらないときは、黙って消さずにプレビューが赤字で知らせます。文字や
マスを小さくするか、段数を増やしてください。

## 保存と読み込み

「**セットを保存**」で、文・語の状態・ヘッダー・設定を含むシート全体を、小さな
`.ktm.json` ファイルとして保存できます。「**セットを読み込み**」であとから開いて、
修正や再印刷ができます。ヘッダーとレイアウトの設定は、次に開いたときにも残ります。

## 知っておくとよいこと

- 例文は Tatoeba のコーパスから、ネイティブまたは上級話者が書いた文に絞って使って
  います。このプロジェクトで書き下ろした文も含みます。市販教科書の文は使っていません。
- JLPT のリストは公式のものではなく、再構成版です。2010年以降、公式リストは公開されて
  いません。
- 画面表示は日本語・英語・フランス語に対応し、上部バーで切り替えられます。テストの
  内容はもちろん日本語です。
- .docx にはフォント全体が入るため、ファイルが 1.5〜5MB ほど大きくなります。PDF の
  ほうがずっと軽くなります。
- 文字やマスを大きくすると、とても長い文は1列に収まらないことがあります。サイズを
  下げるか、段数を増やすか、文を分けてください。
