This project bundles the following components, each under its own license.

| Component | Use | License |
|---|---|---|
| [kuromoji.js](https://github.com/takuyaa/kuromoji.js) (+ `assets/dict/`) | Japanese tokenization / readings, in the browser | Apache-2.0 |
| [docx](https://github.com/dolanmiu/docx) | `.docx` generation | MIT |
| [JSZip](https://stuk.github.io/jszip/) | zip post-processing (font-embed flag) | MIT / GPLv3 (dual) |
| [tesseract.js](https://github.com/naptha/tesseract.js) + [tesseract.js-core](https://github.com/naptha/tesseract.js-core) (in `vendor/tesseract/`) | OCR: read Japanese text from an image, in the browser | Apache-2.0 |
| [pdf.js](https://github.com/mozilla/pdf.js) (in `vendor/pdfjs/`, with its `cmaps/` and `wasm/`) | Read the text of a PDF, and render a scanned one for OCR | Apache-2.0 |
| [ONNX Runtime Web](https://github.com/microsoft/onnxruntime) (in `vendor/onnx/`) | Runs the text recognizer below | MIT |

|---|---|---|

## Text recognition model (in `assets/ppocr/`)

Loaded only when a page is scanned. This is the reader that is tried first;
tesseract, above, is the fallback for pages it cannot be given lines from.

| Data | Source | License |
|---|---|---|
| `rec.onnx.gz`, `dict.txt` (`manga_rec_v0.1`, the recognition half of PP-OCRv6_manga) | [Kellenok/PP-OCRv6_manga](https://huggingface.co/Kellenok/PP-OCRv6_manga), a fine-tune of [PP-OCRv6](https://github.com/PaddlePaddle/PaddleOCR) on Manga109-s and AnimeText | Apache-2.0 |

| Font | Source |
|---|---|

## Data (in `assets/data/`)

The lesson picker bundles data derived from these sources, generated by the
scripts in `tools/` (`build-data.mjs`, `build-sentences.mjs`, `build-parts.mjs`,
`build-words.mjs`).

| Data | Derived from | License | Built into |
|---|---|---|---|
| Kanji grade / stroke count / radical / readings | [KANJIDIC2](https://www.edrdg.org/wiki/KANJIDIC_Project.html) (Electronic Dictionary Research and Development Group) | CC BY-SA 4.0 | `assets/data/kanji.json` |
| Reconstructed JLPT level (N5–N1) per kanji | [davidluzgouveia/kanji-data](https://github.com/davidluzgouveia/kanji-data) (unofficial; no official JLPT list since 2010) | MIT | `assets/data/kanji.json` (`j` field) |
| Example sentences | [Tatoeba Project](https://tatoeba.org/) (Japanese sentences) | CC BY 2.0 FR | `assets/data/lesson-kanji/*.json` |
| ~39 authored example sentences (rare kanji with no Tatoeba example) | original, this project | MIT | `tools/manual-sentences.json` → merged into the above |
| Words per kanji (multiple-choice picker) | tokenized out of the Tatoeba sentences above | CC BY 2.0 FR | `assets/data/lesson-words/*.json` |
| Kanji components and their positions | [KanjiVG](https://kanjivg.tagaini.net/) (Ulrich Apel) | CC BY-SA 3.0 | `assets/data/kanji-parts.json` |
| Kanji stroke paths, used to draw the invented characters | [KanjiVG](https://kanjivg.tagaini.net/) (Ulrich Apel) | CC BY-SA 3.0 | `assets/data/kanji-strokes.json` |

Per the EDRDG licence, this attribution is also shown on-screen in the app.
The KANJIDIC2-derived file is a Share-Alike work and stays under CC BY-SA 4.0;
the KanjiVG-derived files likewise stay under CC BY-SA 3.0; the rest of this
project's code is MIT (see `LICENSE`). The Tatoeba sentences remain under
CC BY 2.0 FR.
